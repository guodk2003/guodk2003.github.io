232. 用栈实现队列 - 力扣（LeetCode）

请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作（push、pop、peek、empty）：

实现 MyQueue 类：

  • void push(int x) 将元素 x 推到队列的末尾
  • int pop() 从队列的开头移除并返回元素
  • int peek() 返回队列开头的元素
  • boolean empty() 如果队列为空，返回 true ；否则，返回 false

说明：

  • 你 只能 使用标准的栈操作 —— 也就是只有 push to top, peek/pop from top, size, 和 is empty 操作是合法的。
  • 你所使用的语言也许不支持栈。你可以使用 list 或者 deque（双端队列）来模拟一个栈，只要是标准的栈操作即可。

示例 1：

思路：设计栈 A 用于加入队尾操作，栈 B 用于将元素倒序，从而实现删除队首元素。

函数设计：

  1. 加入队尾 push() ： 将数字 val 加入栈 A 即可。

  2. 获取队首元素 peek() ：

    • 当栈 B 不为空： B中仍有已完成倒序的元素，因此直接返回 B 的栈顶元素。
    • 否则，当 A 为空： 即两个栈都为空，无元素，因此返回 -1 。
    • 否则： 将栈 A 元素全部转移至栈 B 中，实现元素倒序，并返回栈 B 的栈顶元素。

  3. 弹出队首元素 pop() ：

    • 执行 peek() ，获取队首元素。
    • 弹出 B 的栈顶元素。

  4. 队列判空 empty() ： 当栈 A 和 B 都为空时，队列为空。

225. 用队列实现栈 - 力扣（LeetCode）

请你仅使用两个队列实现一个后入先出（LIFO）的栈，并支持普通栈的全部四种操作（push、top、pop 和 empty）。

实现 MyStack 类：

  • void push(int x) 将元素 x 压入栈顶。
  • int pop() 移除并返回栈顶元素。
  • int top() 返回栈顶元素。
  • boolean empty() 如果栈是空的，返回 true ；否则，返回 false 。

注意：

  • 你只能使用队列的标准操作 —— 也就是 push to back、peek/pop from front、size 和 is empty 这些操作。
  • 你所使用的语言也许不支持队列。 你可以使用 list （列表）或者 deque（双端队列）来模拟一个队列 , 只要是标准的队列操作即可。

示例：

思路：push() 直接将元素加入队尾；pop() 时，将队列前 n-1 个元素依次从队头取出再放回队尾，使最后进入的元素移动到队头，然后将其弹出，实现栈的出栈；top() 可以先调用 pop() 得到栈顶元素，再将该元素重新 push() 回队列，从而保持原结构不变；empty() 直接判断队列是否为空。

  • 时间复杂度: pop为O(n)，top为O(n)，其他为O(1)
  • 空间复杂度: O(n)

20. 有效的括号 - 力扣（LeetCode）

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

  1. 左括号必须用相同类型的右括号闭合。
  2. 左括号必须以正确的顺序闭合。
  3. 每个右括号都有一个对应的相同类型的左括号。

示例 1：

**输入：**s = “()”

**输出：**true

思路：遍历字符串时，遇到左括号就入栈；遇到右括号时，先判断栈是否为空，如果为空说明没有对应左括号，直接返回 false；否则通过哈希表把三种左括号映射为 1、2、3，右括号映射为 4、5、6，若当前右括号编号减 3 等于栈顶左括号编号，说明匹配成功，弹出栈顶，否则返回 false。遍历结束后，如果栈为空，说明所有左括号都被匹配，返回 true；否则返回 false。

  • 时间复杂度: O(n)
  • 空间复杂度: O(n)

1047. 删除字符串中的所有相邻重复项 - 力扣（LeetCode）

给出由小写字母组成的字符串 s，重复项删除操作 会选择两个相邻且相同的字母，并删除它们。

在 s 上反复执行重复项删除操作，直到无法继续删除。

在完成所有重复项删除操作后返回最终的字符串。答案保证唯一。

示例 1：

思路：用 string 充当栈，遍历字符串中的每个字符 ch。如果“栈”不为空且栈顶字符 st.back() 与当前字符相同，说明出现一对相邻重复字符，就用 pop_back() 将栈顶删除；否则将当前字符加入字符串末尾。由于每次消除后，前面的字符会重新成为新的相邻字符，所以这种栈式处理可以自动处理连续消除。遍历结束后，st 中剩下的就是最终结果。

  • 时间复杂度: O(n)
  • 空间复杂度: O(1)（返回值不计空间复杂度）

239. 滑动窗口最大值 - 力扣（LeetCode）

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

返回 滑动窗口中的最大值 。

示例 1：

思路：用双端队列维护一个“单调递减队列，队列中存的是元素下标。

  • 遍历数组时，先把队尾所有小于等于当前元素 nums[i] 的下标弹出，因为这些元素既更小又更早，不可能再成为后续窗口最大值，然后将当前下标 i 加入队尾；

  • 接着计算当前窗口左端点 left = i - k + 1，如果队首下标小于 left，说明它已经离开窗口，将其弹出。由于队列始终按对应元素值单调递减，所以 q.front() 始终是当前窗口最大值的下标；

  • 当 left >= 0、即窗口完整形成后，记录 ans[left] = nums[q.front()]。每个下标最多入队、出队一次。

可以看下 k神的图解

  • 时间复杂度: O(n)（n 为数组的长度。虽然二重循环，但队列入队 n 个元素，所以出队至多执行 n 次）
  • 空间复杂度: O(k)

347. 前 K 个高频元素 - 力扣（LeetCode）

给你一个整数数组 nums 和一个整数 k ，请你返回其中出现频率前 k 高的元素。你可以按 任意顺序 返回答案。

示例 1：

**输入：**nums = [1,1,1,2,2,3], k = 2

输出：[1,2]

桶排序

思路：先用 unordered_map 统计每个数字出现的次数，并记录最大频率 max_cnt；然后建立 vector<vector<int>> buckets(max_cnt + 1)，其中 buckets[c] 用来存所有出现 c 次的数字，相当于把原来的“数字 → 频率”反过来变成“频率 → 数字”。最后从 max_cnt 开始倒序遍历各个桶，把高频率桶中的元素依次加入答案，直到取够 k 个。

  • 时间复杂度: O(n)
  • 空间复杂度: O(n)

堆排序

思路：先用 unordered_map 统计每个数字出现的次数，得到“数字 → 频率”；然后建立一个小顶堆，堆中每个元素用 pair<int,int> 存 {频率, 数字}。遍历哈希表时把每个 {频率, 数字} 压入堆，如果堆的大小超过 k，就弹出堆顶，也就是当前频率最小的元素，这样堆里始终只保留频率最高的 k 个数字。最后依次弹出堆中元素，将其中的数字加入答案即可。

  • 时间复杂度: O(n log k)（堆操作为 logk，共 n 次）
  • 空间复杂度: O(n)
  1. priority_queue<元素类型, 底层容器, 比较规则>，默认大顶堆，greater<> 表示小顶堆。
  2. map/vector/set 本身就是容器；stack/queue/priority_queue 是容器适配器，需要借助一个底层容器来存数据。红黑树、哈希表这些叫底层数据结构，不叫底层容器。

multimap 做法

思路：自己想到 multimap 的 key 值是有序排列的，从小到大排列，可以先用 ordered_map 存储每个数字出现的次数，再用 multimap 把 key 和 value 翻转存储，相较于桶排序思路是一样的，把 数字 -> 频率 反过来成 频率 -> 数字，不过选的数据结构更复杂点

注：

  1. multimap 底层实现为红黑树，内存不连续，不能 it += 1，只能沿着树结构一步步找，it++ 本质上不是“地址加 1”，而是调用迭代器自己定义好的“去下一个元素”的操作。
  2. rbegin() 是 reverse begin，反向迭代器的起点，++ 仍表示继续遍历
  • 时间复杂度: O(n log n)（最坏 n 个元素都不同，都需插入，每次操作 logn，共 n 次）
  • 空间复杂度: O(n)
