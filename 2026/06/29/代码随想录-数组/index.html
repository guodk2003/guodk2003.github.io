704. 二分查找 - 力扣（LeetCode）

题目

给定一个 n 个元素有序的（升序）整型数组 nums 和一个目标值 target ，写一个函数搜索 nums 中的 target，如果 target 存在返回下标，否则返回 -1。

你必须编写一个具有 O(log n) 时间复杂度的算法。
示例 1:

1. 左闭右闭写法（推荐）

思路

target 是在一个在左闭右闭的区间里，也就是[left, right] ：

  • while (left <= right) 要使用 <= ，因为 left == right 是有意义
  • if (nums[middle] > target) right 要赋值为 middle - 1，因为当前这个 nums[middle] 一定不是target，那么接下来要查找的左区间结束下标位置就是 middle - 1

思路比较好理解，复杂度如下：

  • 时间复杂度：O(log n)
  • 空间复杂度：O(1)

代码

2. 左闭右开写法

思路

相较于上述写法只有三点不同，其余一切同：

  • r = nums.size() 右区间取不到

  • while (left < right)，这里使用 < ，因为left == right在区间[left, right)是没有意义的

  • if (nums[middle] > target) right 更新为 middle，因为当前nums[middle]不等于target，去左区间继续寻找，而寻找区间是左闭右开区间，所以right更新为middle，即：下一个查询区间不会去比较nums[middle]

27. 移除元素 - 力扣（LeetCode）

题目

给你一个数组 nums 和一个值 val，你需要原地移除所有数值等于 val 的元素。元素的顺序可能发生改变。然后返回 nums 中与 val 不同的元素的数量。

假设 nums 中不等于 val 的元素数量为 k，要通过此题，您需要执行以下操作：

  • 更改 nums 数组，使 nums 的前 k 个元素包含不等于 val 的元素。nums 的其余元素和 nums 的大小并不重要。
  • 返回 k。

示例 1：

1. 暴力解法

思路

直接两层 for 循环，第一层遍历数组元素，第二层循环根据条件更新数组。

  • 第一层的数组长度是在变化的。
  • 第二层 for 循环后注意 i 此时位置上的值并未比较，退到前一位

复杂度如下：

  • 时间复杂度：O(n^2)
  • 空间复杂度：O(1)

代码

2. 双指针算法（快慢指针）

思路

快慢指针分别指向原数组和新数组：

  • 快指针遍历完整数组
  • 慢指针只将符合标准的元素纳入新数组，不符合的会被覆盖

示例 1：

  • 时间复杂度：O(nlogn)

2. 双指针算法

思路

209. 长度最小的子数组 - 力扣（LeetCode）

题目

给定一个含有 n 个正整数的数组和一个正整数 target 。

找出该数组中满足其总和大于等于 target 的长度最小的 子数组 [numsl, numsl+1, ..., numsr-1, numsr] ，并返回其长度。如果不存在符合条件的子数组，返回 0 。

示例 1：

1. 暴力解法

解法还是双重 for 循环，第一层 for 循环表示子序列起点，第二层表示每次子序列的终点，当前子序列值之和超过 target 后立即更新并 break（后面有符合的长度肯定比当前长）

时间复杂度：

  • O(n^2)

只能通过 18 / 23 的样例。

2. 滑动窗口

思路

滑动窗口也可以理解为双指针法的一种！实现滑动窗口一般要确定如下三点：

  • 窗口内是什么？ 其和 ≥ s 的长度最小的连续子数组。
  • 如何移动窗口的起始位置？ 如果当前窗口的值大于等于s了，窗口就要向前移动了（该缩小了）。
  • 如何移动窗口的结束位置？ 就是for循环里的索引。

用 i 指向窗口左端点，用 j 指向窗口左端点，每次窗口右端点右移后，如果满足条件可以让窗口左端点右移缩小范围看是否符合条件，i 不用从 0 开始因为之前已算过 i 到 j（上一轮）满足条件，j 右移后那也肯定满足，而要求的是最小子序列，故 i 接着右移就行，不用重新来（精髓！🧐）

时间复杂度：i 和 j 分别遍历一遍数组，共 2n。

  • O(n)
